# نظافة السكن 🧹

تطبيق ويب لجدول نظافة السكن (محسن، أمير، نشوان، علي): دور يومي بالتناوب، قائمة تنظيف شاملة، توثيق بالصور، سجل، وإشعارات للجوال.

- يفتح من أي متصفح بدون تسجيل دخول، برابط السكن: `https://sss712011629-hash.github.io/sakan/#<HOUSE_ID>`
- البيانات والصور: Firebase Firestore (الخطة المجانية Spark). الصور تنضغط في الجوال قبل الرفع.
- الإشعارات: Firebase Cloud Messaging، يرسلها GitHub Actions (`.github/workflows/notify.yml`):
  - ٩:٠٠ الصبح بتوقيت السعودية: «اليوم النظافة على …» للكل، وتنبيه خاص لصاحب الدور.
  - كل ١٥ دقيقة: لما أحد يأكد «تم التنظيف» يوصل إشعار للكل (مرة وحدة).
  - ٩:٠٠ المساء: إذا ما توثّقت النظافة، تذكير للكل.

## الملفات
| الملف | وش فيه |
|---|---|
| `index.html` | التطبيق كامل |
| `config.js` | إعدادات Firebase العامة + مفتاح الإشعارات (VAPID) + الترتيب الافتراضي |
| `firebase-messaging-sw.js` | استقبال الإشعارات والتطبيق مقفل |
| `manifest.webmanifest`, `icons/` | الإضافة للشاشة الرئيسية |
| `firestore.rules` | قواعد الحماية (انسخها في Firebase → Firestore → Rules) |
| `scripts/notify.mjs` | إرسال الإشعارات |

## الأسرار في GitHub (Settings → Secrets and variables → Actions)
- `FIREBASE_SA`: محتوى ملف JSON من Firebase → Project settings → Service accounts → Generate new private key
- `HOUSE_ID`: رمز السكن (نفس اللي بعد # في الرابط)

## ملاحظات
- الآيفون: الإشعارات تشتغل بس بعد «إضافة إلى الشاشة الرئيسية» من سفاري (iOS 16.4 وأحدث).
- أي واحد معه الرابط يقدر يدخل، فلا ترسله إلا لأصحاب السكن.
